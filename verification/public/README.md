# Public evidence

These files are copied from actual command executions without editing raw stdout/stderr. Each receipt includes output hashes, command, environment and source-file hashes. `verification_status` derives from the subprocess outcome; it is not an agent-authored approval. Public fixtures are synthetic and the selected logs contain no credentials or resume data.

The reference, its three negative controls, two browser layouts and tiny benchmark are not full Rust product verification. Read the repository verification report for source/commit scope, limitations and recorded failures. Private model routing, portfolio research and execution-state checks are excluded from this directory.
